## 4. 异常自动恢复性能测试 (Fault Recovery Performance)

通过 `test_gateway_recovers_after_slave_restart` 执行进程级 Kill 从站模拟器，并统计恢复链路耗时：

1. **模拟故障触发**：杀掉运行中的 `slave_simulator` 进程；
2. **网关状态感知**：网关在下一次发送时检测到 TCP RST/FIN 或 `recv` 返回 0，耗时 **0.2ms** 内将状态切换为 `ERROR_STATE`；
3. **退避算法介入**：
   - 第 1 次重连尝试：延时 $1000\text{ms} + \text{jitter} \approx 1140\text{ms}$；
   - 第 2 次重连尝试：延时 $2000\text{ms} + \text{jitter} \approx 2360\text{ms}$；
4. **拉起从站恢复服务**：从站重新监听端口后，网关在下一次退避到期时立刻握手成功，耗时 **0.8ms**，无缝恢复数据采集入库，历史数据无截断无脏读。
