阶段 0 的常见错误与排查：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 带 `Q_OBJECT` 的类链接报 `undefined reference to vtable` | 忘记开启 AUTOMOC，或手写了 `#include "xxx.moc"` 但没有 moc 产物 | 确认 `CMAKE_AUTOMOC ON`，且 QObject 派生类的头文件在目标源文件列表里 |

## 二 阶段 1 验收：协议编解码层

### 验证命令

```powershell
.\scripts\build_portable_tests.ps1
```

等价的手工命令（Windows，MinGW）：

```powershell
g++ -std=c++17 -Wall -Wextra -O1 -I include -o build_portable/portable_tests.exe `
    src/protocol/Crc16.cpp src/protocol/ExceptionCode.cpp `
    src/protocol/ModbusFrame.cpp src/protocol/ModbusCodec.cpp `
    tests/portable/portable_tests.cpp
.\build_portable\portable_tests.exe
```

`gateway_cli` 单独编译（它有自己的 `main`，不能和测试文件放进同一个可执行文件）：

```powershell
g++ -std=c++17 -Wall -Wextra -O1 -I include -o build_portable/gateway_cli.exe `
    src/protocol/Crc16.cpp src/protocol/ExceptionCode.cpp `
    src/protocol/ModbusFrame.cpp src/protocol/ModbusCodec.cpp src/gateway_cli.cpp
.\build_portable\gateway_cli.exe
```

### 已知边界

1. 阶段 1 只实现寄存器读写（0x03/0x04/0x06/0x10）。线圈与离散输入（0x01/0x02/0x05/0x0F）
   在阶段 3 随从站模拟器的位数据区一起实现；
2. RTU 的 3.5 字符静默时间属于链路层时序，本地测试无法覆盖，阶段 4 在虚拟串口上用
   人为延时验证；
3. Qt Test 用例（`tests/unit/`）与可移植用例覆盖同一批向量，尚未在本机执行，
   装好 Qt 6 后应执行 `ctest --test-dir build --output-on-failure` 补齐这条证据。
